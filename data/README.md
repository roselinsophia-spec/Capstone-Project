## Official BBO starter data

This folder contains the official initial input and output arrays supplied in
Mini-lesson 12.8: Data and descriptions of functions for Bayesian optimisation
competition.

The project contains eight synthetic black-box maximisation functions. Each
function folder contains:

- `initial_inputs.npy` — the initial evaluated query points
- `initial_outputs.npy` — the corresponding observed outputs

These are official course-provided observations. Model-generated query
recommendations are stored separately under `results/` and must not be
interpreted as evaluated hidden-function outputs.
