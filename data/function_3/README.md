## Function 3: Three-dimensional transformed objective

Function 3 accepts three inputs and is presented as analogous to selecting the
quantities of three compounds while reducing adverse effects. The course frames
the task as maximisation by transforming the naturally minimised response.
Consequently, a less-negative output is better.

The official initial dataset contains 15 observations. The hidden function
itself remains unavailable.

Function-specific interpretation:
Every observed Function 3 output is negative. Because this is a maximisation

the three-dimensional response surface.
