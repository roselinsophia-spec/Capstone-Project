# Notebooks

This folder contains analysis code used to support the Black-Box Optimisation (BBO) capstone project.

## Contents
- `bbo_analysis.py` - a simple, reproducible script for recording query history, summarising outputs, and tracking optimisation progress across rounds

## Purpose
The goal of this folder is to make the optimisation process easier to follow and reproduce by showing how query history and returned outputs can be organised and analysed.
