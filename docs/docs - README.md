# Documentation

This folder contains supporting documentation for the Black-Box Optimisation (BBO) capstone project.

## Contents
- `datasheet.md` - documents the dataset used in the project, including the query history, returned function evaluations, motivation, composition, collection process, intended uses, distribution, and maintenance.
- `model-card.md` - describes the optimisation approach, including its purpose, intended use, strategy evolution, assumptions, limitations, performance, and transparency considerations.

## Purpose
The documents in this folder are intended to improve transparency, reproducibility, and interpretability. They help explain not only what was done in the project, but also why particular modelling and optimisation decisions were made.
